# 建造物のドット絵を追加・修正する

`tools/` と `preview/` は git の管理外（ローカルにだけある）。リポジトリに入るのは生成物の `tiles/b_<id>.png` と `tiles/buildings.js`。

| ファイル | 中身 |
|---|---|
| `tools/buildings.mjs` | 定義 `BUILDINGS`、キャンバス `Spr`、色、城壁・橋（`LINE`）、畑・町の地面 |
| `tools/models.mjs` | 形が決まった建造物（`DRAW`）、高さ可変の塔（`towerOf(h)`）、町の家並み（`DECO`）の **3D モデル** |
| `tools/render3d.mjs` | 3D → ドット絵のレンダラー（SDF、斜め見下ろし、光は北西の上から） |
| `tools/gen-buildings.mjs` | シート生成と見切れチェック |
| `tools/try3d.mjs` | 3D モデルだけを素早く試し描き → `preview/try3d.png`（4倍、マスの枠つき） |

## 見た目の方針

マップは見下ろし型なので、建造物も **斜め上から見下ろした絵** にする（横から見た立面図にしない）。

- 形が決まった建造物と町の家並みは、`models.mjs` で 3D の形（`box`/`cyl`/`cone`/`gable`/`hip`/`ell` など）を組み、`render3d.mjs` で描く。屋根や上面が大きく見え、正面の壁は `K`（0.62）倍に縮んで見える。光と影の向きは地形とそろう。
- 円錐の屋根は「高さ × K > 底の半径」にしないと、尖らずに玉に見える。
- 切妻屋根は、棟を東西（`axis: "x"`）にすると手前の斜面が見える。南北（`axis: "y"`）にすると正面に三角の妻が見える。混ぜると単調にならない。
- 窓・扉・瓦の段は材質の関数で描く（`facing` で南を向いた面だけ、`dv` で明るさの足し引き）。旗や光の筋など形にしにくいものは、`finish()` の `touch` で画素を直接置く。
- 城壁・橋・畑・町の地面は 2D のまま（`buildings.mjs`）。

## 手順

1. 定義（`buildings.mjs` の `BUILDINGS`）と 3D モデル（`models.mjs`）を編集する。
2. 形を詰めているあいだは `node tools/try3d.mjs [id ...]` で試し描きし、`preview/try3d.png` を Read ツールで見る（1〜2 秒で終わる）。
3. `node tools/gen-buildings.mjs --bbox --preview` を実行する。
4. **見切れチェック**（下）を全部確認する。
5. ブラウザで `index.html` を開き、実際の地形の上で見る。

## 見切れチェック（必ずやる）

### 1. 生成スクリプトのチェックが通ること

`gen-buildings.mjs` は `fixed` の絵（高さ可変は高さごと）と `area` の飾りについて次を調べる。1つでも引っかかると「見切れています:」と出して終了コード 1 で止まり、何も書き出さない。

- **枠に収まらない**: 「絵が WxH あり、… に収まりません」。輪郭と影を含めた絵の範囲が枠より大きい。
- **キャンバスの外に描いた**: 「キャンバスの外に Npx」。
- **外周に何かある**: 「外周 Mpx に Npx (x,y …)」。輪郭や影がマスの端で切れているか、町の石垣に飾りが重なっている。

**直し方**: 座標をずらしてごまかさず、形そのものを小さくする（半径・高さを減らす、家を詰める）。収める位置は `fit()` が自動で決める（下端そろえ、左右は中央）。

### 2. `--bbox` の数字に余裕があるか見る

`--bbox` を付けると「絵の大きさ WxH / 枠 WxH」が出る。枠ぴったりの絵は、少し足しただけで見切れるので注意する。

| 種類 | 枠（輪郭・影込み） |
|---|---|
| fixed 1×1 | 30×30（外周 1px を空ける） |
| fixed 2×2 | 62×62 |
| 塔（2×h、h = 3〜6） | 62×(32h − 2) |
| 町の飾り（`fit: { margin: 3 }`） | 26×26（石垣の内側） |

3D の絵は、画面上の高さが「奥行き（y の幅）＋ 高さ × K」になる。背の高いものは足もとの奥行きを小さくする。地面の影は `render()` の `reach`（既定 7px）までしか落ちない。

### 3. プレビューを目で見る

`preview/buildings.png`（3倍）を Read ツールで開いて確認する。

- 旗・塔の先・屋根の上端・影の右下が切れていないか（数字のチェックは透明でない画素しか見ないので、形として不自然かどうかは目で見る）。
- 3D の絵が「横から見た絵」に戻っていないか。屋根や上面が見えているか。円錐が玉に見えていないか。
- 線状（城壁・橋）の 16 通りが、隣のマスとちょうどつながるか。
- 面状（畑・町）の角がきれいにつながるか、飾りが石垣に重なっていないか。

### 4. ブラウザで確認する

マップの端のマスや、大きな建造物が画面の端で切れて一部だけ見えている状態は、プレビューでは分からない。ズーム 150% 以上で、塔なら全部の高さを置いて見る。

## 絵を描くときの決まり

- 3D の絵は `finish(scene, w, h, opts, touch)` を通す（`render()` → `touch` で手直し → `outline()` → `fit()`）。影はレンダラーが地面に落とすので、`shadow()` は呼ばない。
- 2D で描く場合は `Spr.padded(w, h)` から始めて `.outline().shadow().fit()` を通す。`new Spr(32, 32)` に直接描くと、はみ出しても気づけない（城壁・橋・地面のように、マスの端まで描いて隣とつなげるものだけが例外）。
- 高さ可変（`hs: [最小, 最大]`）の絵は、高さごとに `w*32 × h*32` で作る。土台は一番下の段に置く（地形を見るのは一番下の段だけ）。
- 半透明の画素（光の筋など）には輪郭が付かない。
- 地形の id を変えたら `on` / `near` も直して再生成する（存在しない id があるとエラーになる）。
