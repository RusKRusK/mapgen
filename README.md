# mapgen

WFC（Wave Function Collapse）でワールドマップを作るエディタ。`index.html` をブラウザで開くだけで動く（サーバ不要）。

## 操作

| 操作 | |
|---|---|
| 左クリック / ドラッグ | 選択中の地形を置く（置けないマスは赤枠） |
| Shift + 左 | 強制配置。矛盾する周囲を消して自動で埋め直す |
| 右クリック / ドラッグ | 消す |
| Alt + 左 | スポイト |
| 候補パネル | 未確定マスにホバーすると横に出る。クリックで配置 |
| ホイール / Space+ドラッグ / 中ドラッグ | ズーム / 移動 |
| 1〜0, Q〜P, A | 地形を選ぶ |
| [ ] | ブラシサイズ |
| G / F / H / Esc | 生成 / 空きを埋める / 全体表示 / 生成停止 |
| Ctrl+Z / Ctrl+Y / Ctrl+S | 元に戻す / やり直す / JSON保存 |

- 置くと8近傍の候補が絞られ、候補が1つになったマスは即確定する
- パレットの字下げは親子関係。隣接できるのは「同じ・親・子・兄弟」だけ
- パレットのスライダーはWFCの出現重み（行のダブルクリックで初期値）
- 地形ノイズ: 0 で純粋なWFC。上げると標高・湿度・気温ノイズに沿って地形を選ぶ
- シード欄で Enter → そのシードで生成（固定ON）
- 状態はブラウザ（localStorage）に自動保存

## タイル

`tiles/<id>.png` は 160×32。16×16 のピースを次の順に並べたもの。

```
①②⑤⑥⑨⑩⑬⑭⑰⑱
③④⑦⑧⑪⑫⑮⑯⑲⑳
```

①〜④ 凸角（左上・右上・左下・右下）、⑤⑥ 左フチ上下、⑦⑧ 右フチ上下、⑨⑩ 上フチ左右、⑪⑫ 下フチ左右、⑬〜⑯ 凹角、⑰〜⑳ 内部。
各マスは象限ごとに（横・縦・斜め）の隣接から1つ選んで 32×32 を組む。フチの外側は透明で、親地形の内部が下に敷かれる。

```
node tools/gen-tiles.mjs            # 全タイル再生成 + tiles/terrains.js
node tools/gen-tiles.mjs grass      # 1種類だけ
node tools/gen-tiles.mjs --pack     # PNGを手で描き直したとき: 埋め込みだけ更新
node tools/gen-tiles.mjs --preview  # preview/ に形状テスト・シート一覧・生成例
```

地形の追加: `tools/terrains.mjs` に定義、`tools/art.mjs` に絵（`interior()` で内部32×32、`edge` でフチ）。
タイル生成は [pixelfx](https://github.com/patch-gg/pixelfx) の core（パレット、周期ノイズ、PNG書き出し、MIT）を `tools/pixelfx/` に同梱して使用。
